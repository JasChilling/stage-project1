# Project Management Application

A full-stack project management application inspired by
Trello/Jira.

## Technologies

### Frontend

- Angular
- TypeScript
- HTML
- CSS

### Backend

- Node.js
- Express.js
- JavaScript
- MongoDB
- Mongoose
- JWT

### Development Tools

- Visual Studio Code
- Git
- GitHub
- Thunder Client
- MongoDB Compass
- MongoDB Atlas



## Prerequisites

Install:

- Node.js
- npm
- Angular CLI
- Git
- MongoDB account

MongoDB Atlas is used as the database.

## Clone the repository

git clone https://github.com/JasChilling/stage-project1.git

cd stage-project1


## Backend

cd backend

npm install

npm run dev

## Frontend

cd frontend

npm install

ng serve

Frontend:
http://localhost:4200

Backend:
http://localhost:5000
